# Car Control Pro — ESP32-S3
این نسخه رابط V3 را با Firmware زمان‌محور ادغام می‌کند و برای کنترل شیشه‌ها به INA219 یا سنسور جریان نیاز ندارد.

## تنظیمات
- Board: ESP32S3 Dev Module
- AP: Car_Control_Pro
- Password: 12345678password
- IP: 192.168.4.1
- UP/CLOSE: 5.0 ثانیه
- DOWN/OPEN: 3.5 ثانیه
- Relay: Active HIGH
- Inputs: 4,5,6,7
- Outputs: 15,16,17,18

## نکته
موقعیت شیشه در این نسخه فقط تخمینی و زمان‌محور است. نقطه شروع نرم‌افزار 0% = بسته است. چون فیدبک واقعی موقعیت وجود ندارد، اگر شیشه واقعاً در موقعیت دیگری باشد، نمایش درصد دقیق نخواهد بود.

فایل index.html نسخه مستقل رابط نیز کنار sketch قرار دارد.
