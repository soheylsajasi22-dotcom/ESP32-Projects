# چانج‌لاگ

## v5.6 — نسخهٔ فعلی فریم‌ور

- پنل وب کامل به‌صورت تک‌فایل داخل `PROGMEM` (بدون LittleFS) — آپلود با یک فایل.
- معماری چهار لایه با ناورداهای I1–I6.
- مدل تخمین موقعیت: زمان + عدم‌قطعیت σ، کالیبراسیون با میانهٔ ۳ نمونه.
- اصلاح سرعت حرکت بر اساس ولتاژ باتری.
- تشخیص لبهٔ مسیر با افت ولتاژ (sag) هنگام حرکت.
- صف صحنه‌ها: `close` / `open` / `vent` / `park` / `safety` — هرگز دو موتور هم‌زمان.
- ژست‌های لمسی: دابل‌تپ و تریپل‌تپ با صحنه‌های قابل انتخاب.
- لاگ ساختاریافته (۱۲۰ رویداد در RAM) + ماندگاری ۲۰ رویداد آخر در NVS + خروجی CSV.
- تب دیاگنostics: ورودی‌های لمسی زنده، تست تکی رله، ولتاژ/جریان/توان.
- قفل ولتاژ پایین (9.5V)، حداکثر زمان رله، زمان مردهٔ ۱۵۰ms بین جهت‌ها.
- واچ‌داگ سخت‌افزاری و قطع رله‌ها هنگام OTA.
- OTA با ElegantOTA و امکان فعال‌سازی Basic Auth.
- mDNS با نام `pride.local`.

## v6.0-dev (شاخهٔ سورس فعلی)

- پل BLE (NimBLE) با همان موتور کنترل، بدون نیاز به Wi-Fi:
  - پروتکل JSON خط‌به‌خط
  - احراز هویت با توکن یک‌بارمصرف
  - انتقال تکه‌تکهٔ داده با base64 برای لاگ و CSV
  - قطعه‌بندی امن نسبت به MTU همتا
- کانال‌های LED با حالت‌های `steady` / `flash` / `dance` / `police` / `plane`.
- محافظت از پایه‌های ناامن در درایور LED (فهرست پایه‌های مجاز).
- حالت «Wi-Fi مهمان» قابل قطع از پنل.

> سورس فعلی مخزن شامل این بخش‌هاست؛ آخرین فریم‌ور آمادهٔ فلش در `releases/` مربوط به v5.6 است.
